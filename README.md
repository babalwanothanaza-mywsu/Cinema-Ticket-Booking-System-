# Cinema Ticket Booking System

A C++ application designed to simplify the process of booking cinema seats.

## Features

- Book seats
- Cancel bookings
- Display available seats

## Concepts Used

- Object-Oriented Programming
- Classes
- Arrays
- Exception Handling

## Project Structure

- `include/` - Header files
- `src/` - Source code files
- `docs/` - Project documentation
- `tests/` - Testing files
- `presentation/` - Project presentation

## Group Project

This project was developed as part of an Introduction to Object-Oriented Programming course.
